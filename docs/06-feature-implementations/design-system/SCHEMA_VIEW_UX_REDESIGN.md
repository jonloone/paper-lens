# Schema View UX Redesign
## Progressive Disclosure for Better Scannability

---

## Problem Statement

### Current Issues

**SchemaTab.tsx** (Table Detail Panel):
```
Current Layout (requires horizontal scroll):
┌──────────────┬────────┬──────────┬─────────┐
│ Column       │ Type   │ Nullable │ Null %  │
├──────────────┼────────┼──────────┼─────────┤
│ customer_id  │ bigint │ Required │ 0.0%    │
│ email        │ varchar│ Yes      │ 0.0%    │
│ first_name   │ varchar│ Yes      │ 0.2%    │
│ ...          │ ...    │ ...      │ ...     │
└──────────────┴────────┴──────────┴─────────┘
```

**Problems**:
1. **Too many columns** - Forces horizontal scroll on narrow panels
2. **Low information density** - Repeating "Yes/No" wastes space
3. **No hierarchy** - Everything visible at once, hard to scan
4. **No context** - Type alone doesn't explain purpose
5. **No sample values** - Can't understand actual data

**SampleDataTab.tsx**:
```
Current: ✅ Already uses a table (good!)
Issue: Separate tab, disconnected from schema
```

---

## Design Principles

### 1. **Scannability First**
Show column names + key metadata in compact list, hide details until clicked

### 2. **Progressive Disclosure**
- **Level 1**: Name + type + critical flags (scannable list)
- **Level 2**: Constraints, stats, description (expand inline)
- **Level 3**: Sample values, lineage, usage (modal/drawer)

### 3. **Visual Hierarchy**
Use color, icons, and typography to guide the eye to important information

### 4. **Reduce Cognitive Load**
Icons > Text (PK icon vs "Primary Key" badge)

## Detailed Specification: Option C (Recommended)

### Compact List Component

```typescript
interface CompactSchemaListProps {
  columns: SchemaColumn[];
  onColumnClick: (column: SchemaColumn) => void;
  selectedColumn?: SchemaColumn;
}

interface SchemaColumn {
  name: string;
  type: string;
  nullable: boolean;
  isPrimaryKey?: boolean;
  isForeignKey?: boolean;
  isPII?: boolean;
  nullRate: number;
  description?: string;
}
```

**Visual Hierarchy**:
```css
Column Name:  font-mono text-sm font-medium
Type:         font-mono text-xs text-muted-foreground
Flags:        Icons (12px) with hover tooltips
Hover:        bg-muted/50 cursor-pointer
Selected:     bg-primary/10 border-l-2 border-primary
```

**Icons**:
```
🔑 = Primary Key (golden key icon)
🔗 = Foreign Key (link icon)
💼 = PII/Sensitive (lock icon)
⚠️ = High null rate >10% (warning triangle, yellow)
🔴 = Very high null rate >50% (red circle)
✓ = Not nullable (green check)
```

## Sample Values Display: Table vs List

### ❌ Current (Inline text):
```
Sample Values: john.doe@example.com, jane@corp.com, bob@startup.io
```

**Problems**: Hard to scan, hard to copy, no structure

### ❌ Alternative 1 (Vertical list):
```
Sample Values:
  • john.doe@example.com
  • jane@corp.com
  • bob@startup.io
  • alice@enterprise.com
```

**Problems**: Takes too much vertical space

### ✅ **Recommended (Compact table)**:
```
Sample Values (5 of 2.8M):

┌──────────────────────────┬──────────────────────────┬──────────────────────────┐
│ john.doe@example.com     │ jane@corp.com            │ bob@startup.io           │

│ alice@enterprise.com     │ mike@agency.net          │                          │

```

**Benefits**:
- **Scannable**: Grid format easy to scan
- **Compact**: 3 columns = fits 6-9 values in less space
- **Copyable**: Easy to select and copy
- **Structured**: Clear boundaries between values

## Accessibility Considerations

- **Keyboard Navigation**: Arrow keys to navigate column list, Enter to open drawer
- **Screen Readers**: Proper ARIA labels for icons, drawer role="dialog"
- **Focus Management**: Auto-focus drawer header on open, restore focus on close
- **Color**: Don't rely on color alone (icons + text for flags)

---

## Mobile Considerations

On narrow screens (<768px):
- Drawer becomes full-screen modal
- List becomes single column
- Sample values table becomes vertical list

## Conclusion

**Recommended Approach**: Option C (Hybrid Compact List + Drawer)

**Why**:
✅ Maximizes scannability (15+ columns visible)
✅ Reduces horizontal scroll to zero
✅ Progressive disclosure (scan → click → details)
✅ Sample values in **table format** (easy to scan)
✅ No tab switching (everything in drawer)
✅ Maintains context (list stays visible)
